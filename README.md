# עוגן מקומי — אב־טיפוס דף נחיתה

Prototype landing page for Ogen Makomi (Hebrew, RTL), built from the site content brief.
A toolbar at the bottom switches between brand directions 05 and 04 and toggles the draft markers.
Open `index.html#d05` or `index.html#d04` to start in a given direction.

Status: prototype. Field examples, the national-catalog link and company details are placeholders pending verification.
